# Prompt para começar uma sessão de estudo

O `CLAUDE.md` já carrega o contexto geral automaticamente. Copie o bloco abaixo, preencha e cole no início de cada sessão nova.

---

```
Assunto de hoje: <ex.: Sliding Window>
Curso / aula: <ex.: DSA + LeetCode, aula 23>

O que entendi da aula (resumo rápido):
- <ponto 1>
- <ponto 2>

Onde fiquei com dúvida:
- <dúvida>

O que quero nesta sessão:
[ ] Aprofundar a teoria (por que funciona, quando usar, variações)
[ ] Implementar a estrutura/algoritmo em Java, com dicas e sem a resposta pronta
[ ] Resolver o LeetCode <número/nome> comigo, com dicas progressivas
[ ] Revisar meu código em <caminho do arquivo>
[ ] Simular uma entrevista sobre o assunto
[ ] Montar o resumo em notas/<pasta>/<arquivo>.md

No final, me sugira 2 ou 3 problemas para fixar e atualize o checklist do README.
```

---

## Variações rápidas

**Revisão de código:**
```
Revise minha implementação em <arquivo>. Aponte bugs, casos de borda que faltam nos testes e a complexidade. Não reescreva por mim, só aponte.
```

**Simulação de entrevista (LeetCode):**
```
Simule uma entrevista técnica: me dê um problema médio de <padrão>, sem dizer o nome. Avalie como eu explico, minha abordagem, a complexidade e o código, como um entrevistador de big tech faria.
```

**Simulação de entrevista (System Design):**
```
Simule uma entrevista de System Design: "Projete um <sistema>". Conduza como entrevistador, com perguntas sobre requisitos, estimativas e gargalos, e me dê feedback no final.
```

**Revisão espaçada:**
```
Escolha um problema que eu já resolvi (veja a tabela do README) e peça para eu refazer do zero, sem olhar o código antigo.
```
